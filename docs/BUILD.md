# Сборка и выпуск

Обычному пользователю нужна команда из README опубликованного релиза. Сборка вручную не требуется.

## Исходники и инструменты

Транспорт сохраняет оригинальный amurcanov/csqtt v2.1.9. Сборки используют Rust1.97.1, Go1.26.8 и точные SDK из platforms/registry.json; архивы SDK проверяются по SHA256, сверяются target/архитектура и компилятор. ARM64 и x86_64 имеют отдельные каталоги Cargo/native objects.

Рабочая станция Windows; Linux/Rust/OpenWrt проверки выполняются GitHub Actions. Локальные Node/Python-тесты не заменяют нативные проверки.

## Проверки

- Validate and build: Rust, Go, LuCI/политики, установщик, выпуск, настоящий ucode/DNS/nftables и прежний reference SDK.
- Official OpenWrt platform checks: соответствие сгенерированного install.sh исходным helper-файлам, portable-тесты и SDK24.10/25.12 для выбранных ABI. Запускается вручную или внутри release workflow; это исключает повторную сборку одинаковой матрицы при отправке одного commit в обе ветки. Старый GLvendor private-runtime job исключён.
- Signed official OpenWrt preview: шесть комплектов кандидатов, три чистых OpenWrt VM-стенда (24.10.8, 25.12.5, 25.12.6), доказательства, подписание и новый draft preview.

Для опубликованного preview.10 квалифицирован исходный commit [`6c70e490585651b9a65d7d128ecc551415c32f4e`](https://github.com/RATOR2000/csqtt-openwrt/commit/6c70e490585651b9a65d7d128ecc551415c32f4e). [Официальный workflow](https://github.com/RATOR2000/csqtt-openwrt/actions/runs/40139753900) завершил шесть SDK-сборок, три чистых OpenWrt VM и подписанную ARM-миграцию r9 → r10 → r9 настоящим APK в изолированной базе без запуска пакетных скриптов. Все пять jobs [общего CI](https://github.com/RATOR2000/csqtt-openwrt/actions/runs/40139752629) прошли. Опубликованные файлы независимо проверены; буквальная HTTPS-команда README прошла на чистых 24.10.8 и 25.12.6. 25 октября 2026 дополнительно подтверждены самостоятельная установка preview.10 на физический GL-MT6000 с официальной 25.12.6 и подключение девяти потоков; полная приёмка VK/Android и испытания отказов остаются отдельными.

Для локальной Linux-сборки кандидата:

```sh
CSQTT_PROFILE=official-25.12.6-mediatek-filogic-aarch64_cortex-a53 CSQTT_PACKAGE_RELEASE=10 bash scripts/build-sdk.sh
```

Без ключа это непубликуемый кандидат. Совместимость не подтверждается одним успешным компилированием.

[Публичная команда установки](https://github.com/RATOR2000/csqtt-openwrt/actions/runs/40184158722) прошла на чистых 24.10.8 и 25.12.6, включая установку недостающих зависимостей, сохранение настроек при повторе и доступность LuCI/DNS/LAN после удаления. Код этого стенда — `6979eb22bf0b0658541d098374e88b63b5b75945`; исходники опубликованного приложения остаются `6c70e490585651b9a65d7d128ecc551415c32f4e`.

## Зависимости и квалификация

Манифест связывает пакеты приложения, полную зависимость от подписанных официальных индексов, их ключи/хеши и точный kernel ABI. Приложение не имеет списка допустимых моделей платы; первая матрица содержит конкретные release/target/package-ABI. Непроверенные варианты безопасно отклоняются.

Каждый ABI проходит ELF/CPU startup/TUN/TLS проверки; release-evidence связывает результат с исходным commit и хешами пакетов. Чистые VM24.10/25.12 используют настоящие пакетные менеджеры и проверяют установщик, повторную установку, сохранение конфигурации и нативные runtime/DNS/firewall/LuCI. Изолированный CI-кандидат с временной квалификацией не публикуется. Финальные манифесты подписываются только после успешных доказательств.

Физические устройства, реальный VK/Android и72часа эксплуатации — отдельные проверки. Они не выводятся из VM/QEMU. Старое наблюдение preview9 не завершено после переустановки прошивки владельцем.

Параметры виртуальных стендов: 768МиБ RAM, два CPU, корневой раздел1ГиБ.
Исходный образ проверяется целиком по закреплённому SHA256; расширение раздела
выполняется только в отдельном временном образе и записывается в доказательства.
Проверки места установщика сохраняются. Приёмка такого стенда не подтверждает
достаточность исходного104МиБ раздела для установки и повторного обновления.

## Подпись и публикация

Используется существующий P256 ключ, привязанный к release/csqtt-public.pem. Закрытый ключ доступен только шагам CI через repository secret; в исходники, журналы или артефакты он не попадает. Публичные ключи официального дистрибутива проверяют зависимости; проектная подпись проверяет каталог/манифест/пакеты клиента.

Опубликованный тег — `v0.1.0-preview.10`, ревизия пакетов10. Существующие опубликованные теги и релизные файлы не перемещаются и не заменяются. Сначала создаётся draft и сверяются скачанные assets, подписи, хеши, исходный commit и доказательства. После публикации независимо проверяются публичные файлы, затем буквальная HTTPS-команда README на чистых 24.10.8 и 25.12.6. Только после обеих успешных проверок команды обновляется README главной ветки.

GitHub нормализует `~` в именах загружаемых файлов. Для preview.10 имена файлов доставки и ссылки на них в подписанных метаданных приведены к этому формату; байты пакетов, внутренние имена и версии, доказательства и установщик сохранены. Подписанные сведения о публикации связывают квалифицированный исходный commit с отдельным commit упаковки. Helper из общего CI того же исходного commit приложен как debug APK с контрольной суммой и сведениями о сборке; это не приёмка Android/VK на устройстве.

Заводские GL.iNet21/fw3 эксперименты сохранены в checkpoints/experiments и не входят в текущую поставку. Все исторические результаты reference25.12.5 и подписанных preview7/9 сохранены в Git и STATUS; они не являются результатами нового выпуска.
