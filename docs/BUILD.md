# Сборка и предварительный выпуск

## GitHub Actions

Workflow `Validate and build` проверяет Node/Go, Rust, Android и политику
через настоящий ucode, dnsmasq и nftables в изолированных Linux namespaces.
После успешных проверок собирает пакеты SDK OpenWrt 25.12.5 для GL-MT6000.
Нативная проверка APK использует временные ключи и отдельные каталоги:
проверяет подписи собранных пакетов, конфликты DNS, кеш зависимостей,
установку без сети и восстановление исходного тестового пакета.
Исходники ucode, dnsmasq, upstream CSQTT и SDK закреплены версией или хешем.

Артефакты CI без подписи подходят для проверки сборки. Установщик принимает
только пакеты и manifest, подписанные ключом проекта.

## Ключ выпуска

Публичный ключ хранится в `release/csqtt-public.pem` и встроен в `install.sh`.
Локальный приватный ключ создан в `.work/signing/release.pem`; файл исключён
из Git. Его нужно хранить отдельно и не отправлять в сообщения или логи.
Владелец репозитория может сохранить содержимое файла в Actions secret
`CSQTT_SIGNING_KEY`. Ключ передаётся только шагу подписи, временный файл удаляется.
Скрипт сборки проверяет соответствие публичному ключу проекта.

`Build signed draft release` запускается вручную с тегом вида
`v0.1.0-preview.1`. Он требует настроенного ключа, выполняет весь CI, проверяет
подпись manifest и хеши пакетов, затем создаёт черновик предварительного выпуска.
Этот workflow не публикует стабильную версию.

## Локальная Linux-сборка

Нужны Rust 1.97.1, Go 1.26.8, Python 3, инструменты сборки SDK и пакеты из
шага `Build dependencies` workflow. Команда: `bash scripts/build-sdk.sh`.
При наличии приватного ключа в `CSQTT_SIGNING_KEY` также создаётся подпись.
SDK загружается в `.work/sdk`, результат — в `dist`; оба каталога исключены из Git.

## Условия стабильного выпуска

Нужны успешные сборки трёх пакетов и Android-помощника, проверка установщика
на целевой версии APK/OpenWrt, а затем реальные проверки на GL-MT6000:
подключение к серверу, смешанные WAN/VPN группы, DNS/IPv6, остановка и сбой
клиента, перезагрузка firewall/роутера и ручная CAPTCHA с телефона в VPN-группе.
Секреты и VK-ссылки остаются на устройствах. Результаты фиксируются в STATUS.
