# preview.10 — установка на чистый OpenWrt и первый запуск

Предварительный выпуск оригинального CSQTT v2.1.9 для официального OpenWrt24.10/25.12. Подписанный каталог содержит точные проверенные варианты; экспериментальная квалификация ABI/стенда не означает проверки каждой модели или реальной CAPTCHA VK.

Установка и обновление выполняются одной командой из README. Установщик проверяет платформу, подписи, зависимости и точное ядро, сохраняет конфигурацию и готовит откат. После установки открывается мастер LuCI: сервер, пароль, ссылка VK и устройства. До явного завершения настройки VPN выключен; настроенные обновления пропускают мастер.

Защищённый трафик не переводится в WAN при остановке или ошибке. DHCP/DNS и управление роутером сохраняются; собственные DNS-процессы CSQTT обслуживают назначенные устройства. Автоматический профиль начинается с9соединений, ручные значения сохраняются. Автовосстановление по умолчанию остаётся выключенным до отдельной приёмки.

Команда и таблица поддержки опубликованы в README и описании [preview.10](https://github.com/RATOR2000/csqtt-openwrt/releases/tag/v0.1.0-preview.10). Исходный commit `6c70e490585651b9a65d7d128ecc551415c32f4e` прошёл шесть SDK-сборок, три чистых OpenWrt VM и общие CI-проверки; подписанная ARM-миграция r9 → r10 → r9 проверена настоящим APK в изолированной базе без запуска пакетных скриптов. Опубликованные файлы независимо проверены; буквальная HTTPS-команда из README прошла на чистых 24.10.8 и 25.12.6. Доказательства, commit и контрольные суммы входят в материалы выпуска.

Android Helper приложен как debug APK с контрольной суммой и сведениями о сборке. Нативная установка preview.10 на роутер владельца не выполнялась: владелец установит релиз самостоятельно. Стендовые проверки не подтверждают физическое устройство или реальную CAPTCHA VK.

Реальные VK/Android, загрузка после неудачной первой активации и длительная эксплуатация остаются условиями стабильного выпуска. Preview8 отозван; preview9 и его прежние файлы не заменяются.
