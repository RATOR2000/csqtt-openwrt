# CSQTT OpenWrt preview.7: защита DNS при неудачной активации

Первая платформа: GL-MT6000, OpenWrt 25.12.5, mediatek/filogic,
aarch64_cortex-a53. Клиент совместим с оригинальным amurcanov/csqtt v2.1.9.

Подписанная предварительная сборка `0.1.0-r7` закрывает DNS TCP/UDP защищённых
клиентов на порту 53 и групповых портах 5400–5415 до готовности новой политики,
включая неудачную первую активацию. DNS с локальными именами временно
приостанавливается; управление по IP и DNS неназначенных клиентов и роутера
доступны. Успешное применение снимает обе цепочки защиты одной транзакцией.

Исходный commit `a690ea728458e2b64fe46e42a8c965036b859313` и commit сборки
`55433d25d21601616a3a77b9343a8f8b04c88db6` имеют дерево
`06b0e9282a4b70154d52e667b40c65a2af675773`. Единственный запуск
[CI37927521094](https://github.com/RATOR2000/csqtt-openwrt/actions/runs/37927521094)
успешно завершил проверки исходников, нативных DNS/сетевых сценариев, Rust и SDK.
Прошли 75 тестов политик/LuCI и 2 теста выпуска на Node, 4 теста выпуска
на Python, 22 теста упакованного LuCI, 6 тестов упакованной службы,
353 теста Rust и отдельный тест TURN; 7 прежних Rust-тестов оставлены
пропущенными. Нативные проверки TCP/UDP IPv4/IPv6 при ошибке первой активации
подтвердили блокировку внешнего DNS для защищённых клиентов. Проверены обычные
DNS/сетевые сценарии, запуск ARM64 и настоящий
Linux TUN, подписи и соответствие пакетов замороженным исходникам.

Тег, размеры, SHA256 и скачанные копии всех восьми публичных файлов совпадают.
Подписанное обновление r7 завершилось с кодом 0: четыре файла настроек сохранены,
11 установленных файлов совпадают с подписанными пакетами, работают 72 канала,
DNS и разные выходы WAN/VPN. Обе временные цепочки защиты пусты; сохранённый
файл содержит снятие обеих блокировок. Изолированное сравнение r6 и
кандидата на настоящем ARM64-роутере подтвердило защиту DNS после ошибки
первой активации и восстановления firewall; это отдельное испытание исходника.

Из preview.6 сохранён запуск CSQTT Helper отдельным нажатием через Android
intent и возврат на обзор LuCI при неудаче. Ручное копирование ссылки доступно;
ссылка возврата не содержит одноразового разрешения. Android-приложение,
брокер, установщик и протокол транспорта не менялись.

Из preview.5 сохранены галочки активности назначенных устройств и единицы
Кб/Мб/Гб в обзоре. Выключенное устройство использует обычный WAN, а его запись
и выбранная группа сохраняются. Применение политик сохраняет текущий процесс
VPN, если настройки подключения не менялись.

На подписанной r5 проверены обновление с сохранением четырёх файлов настроек,
11 установленных файлов, 72 канала, DNS и разные выходы WAN/VPN. Также прошли
проверки аварийного завершения клиента и защиты до запуска CSQTT при обычной
загрузке. Маршрутизируемые TCP/UDP IPv6 проверены через изолированный узел
до и после перезагрузки firewall; IPv6 у провайдера этим не подтверждён.
Настройки владельца сохранены, временные тестовые объекты удалены.

Запуск Helper и ручная CAPTCHA при настоящем запросе VK ещё не подтверждены.
Сценарий неудачной первой активации при загрузке, остальные незакрытые пункты
ACCEPTANCE и наблюдение за периодической потерей VPN-интернета остаются
условиями стабильного выпуска.

В состав входят три пакета OpenWrt, подписанный manifest и отладочный APK
Android-помощника. APK помощника предназначен для проверки; его подпись пока
не закреплена как постоянная подпись обновлений.

Сведения о проверках и ограничениях: [STATUS.md](STATUS.md) и
[ACCEPTANCE.md](ACCEPTANCE.md).
