# Как пользоваться CSQTT

## Установка

Команда и список проверенных платформ находятся в README и описании опубликованного релиза. Выполните команду от root по SSH. Установщик сам проверяет систему, подписи, пакеты и доступное место; вручную заменять dnsmasq или устанавливать LuCI не требуется. Роутер не перепрошивается и не перезагружается.

После установки откройте показанный адрес или **LuCI → Службы → CSQTT**. При обновлении прежние настройки сохраняются.

## Первый запуск

В мастере нужны:

- **Адрес сервера** — имя или IP с портом, например `vpn.example:46000`.
- **Пароль подключения** — пароль вашего сервера CSQTT.
- **Ссылка VK** — полная ссылка на звонок. Дополнительные ссылки можно добавить позже в настройках.

Выберите устройства, которые должны использовать VPN, и завершите настройку. Только это действие сохраняет данные и запускает подключение. Мастер показывает результат проверки: рабочее подключение, ожидание, проблему WAN или необходимость подтверждения VK.

Устройства без активного назначения используют обычный WAN. Новая установка выбирает девять соединений; увеличивать число для первого запуска не требуется. Настроенная ранее установка, включая вручную остановленную, не проходит мастер повторно.

## Ежедневная работа

На странице **Обзор** отдельно показаны процесс, активные соединения, WAN/VPN/DNS и восстановление. Число соединений само по себе не доказывает доступность интернета: ориентируйтесь также на состояние проверки VPN.

**Остановить** выключает клиент и сохраняет защиту назначенных устройств. Их VPN-трафик не переключается в обычный интернет. **Запустить** возобновляет работу. Роутер и локальная панель остаются доступны.

В **Подключение → Дополнительно** доступны число соединений, транспорт и другие параметры. Существующие ручные значения при обновлении не меняются. Автовосстановление включается отдельной галочкой; по умолчанию оно выключено до завершения отдельной приёмки. Перезагрузка роутера не является способом автоматического восстановления.

## Устройства и правила

В **Устройства и политики** можно создать именованные группы и назначить им устройства. Правила доменов/IP применяются по порядку перед действием группы по умолчанию. Назначение выключенного устройства сохраняется, но само устройство использует WAN; повторное включение возвращает политику.

Домен включает поддомены. Распознавание использует DNS роутера: сторонний DoH, кеш и общий IP сайтов ограничивают точность. После изменения группы или правила заново откройте соединение на устройстве.

Для групп, способных использовать VPN, интернет по IPv6 блокируется, а локальный IPv6 сохраняется. Явные исключения WAN продолжают работать согласно политике. При применении изменений DNS защищённых устройств может кратко приостанавливаться; управление по IP сохраняется.

## Подтверждение VK

Настоящая CAPTCHA может потребовать человека:

1. Установите CSQTT Helper из релиза на Android и подключите телефон к LAN/Wi-Fi роутера.
2. На **Обзоре** нажмите **Решить на Android**, затем **Открыть CSQTT Helper**.
3. Если приложение не открылось, скопируйте одноразовую ссылку в Helper вручную.
4. В Helper откройте проверку VK и завершите CAPTCHA. Ответ относится только к текущему сеансу.

Пароли, ссылки VK и одноразовые ссылки Helper не публикуйте. Полная реальная приёмка Android/VK остаётся отдельной проверкой; её успешность не выводится из тестов интерфейса.

## Обновление и ошибки установки

Для обновления повторите команду из нового опубликованного релиза. Установщик сохраняет конфигурацию, идентичность и выбранные устройства. Если операция прервана, повторный запуск должен сначала проверить журнал и восстановить безопасное состояние. При отказе следуйте точному сообщению; несовместимые пакеты или ядро принудительно устанавливать не нужно.

Закрытые журналы и резервные копии хранятся на роутере; установщик выводит их путь. Для обращения за помощью достаточно сообщения об ошибке и сведений о версии OpenWrt, архитектуре и релизе. Сырые конфигурации и приватные журналы в GitHub не загружайте.

## Удаление

Если нужен обычный интернет, сначала выключите активность назначенных устройств в **Устройства и политики** и примените изменения. Затем удалите `luci-app-csqtt`, `csqtt-captcha` и `csqtt` через **Система → Пакеты**. Одна кнопка **Остановить** намеренно сохраняет защиту. Конфигурация, идентичность и резервные копии автоматически не стираются.
