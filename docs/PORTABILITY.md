# Платформы и границы поддержки

Актуальный план от22.10.2026: одна команда для официального OpenWrt24.10/25.12, автоматические зависимости, настройка в браузере. Пользователь самостоятельно устанавливает опубликованный релиз. SSH `router` используется только для согласованного чтения; никаких установок, перезагрузок или сетевых изменений. Задачи Codex по расписанию запрещены.

## Что считается поддержкой

Каталог выбирает совместимый ABI и формат пакетов: opkg/IPK для24.10, APK для25.12. Приложение не привязано к модели платы. Модуль TUN всегда должен соответствовать точной версии работающего ядра и подписанным feeds этой прошивки.

Проверки различаются:

- SDK/ELF/эмуляция: сборка, инструкции процессора, запуск, TLS/TUN.
- Чистый OpenWrt-стенд: настоящие пакетные менеджеры, загрузка, firewall, DNS, IPv6 и отсутствие WAN-утечек.
- Физическое устройство: отдельная запись модели и фактических результатов.
- Реальные VK/Android и длительная работа: самостоятельные условия стабильного выпуска.

Preview может поддерживать ABI по успешным стендовым проверкам без заявления о физической проверке каждой модели. Все результаты должны быть связаны с исходным commit, артефактами и профилем. Простая смена флагов qualification не подтверждает совместимость.

## Очерёдность

ARM64 и x86_64 — первые комплекты; ARMv7 требует явного совпадения CPU/float ABI и нативных зависимостей. MIPS LE/BE остаётся отдельным портированием: текущие Rust AtomicU64/AtomicI64 и Tier3 std/toolchain требуют адаптации.

Автопрофиль новых установок начинает с девяти соединений. Явные существующие параметры сохраняются. Повышать автоматические уровни и публиковать минимумы памяти можно по измерениям, а не по предположению.

## Ресурсные измерения

`scripts/measure-resources.sh PID SCENARIO [SAMPLES [SECONDS]]` — ручной инструмент чтения для отдельного стенда или владельца. Сверяет исполняемый файл и startticks, выдаёт JSONL с RSS/HWM, CPU ticks, доступной RAM и boot time; не читает argv, не создаёт трафик, авторизацию или сбой. Сценарии: idle/auth/traffic/recovery. Учитывайте код завершения: частичный файл не означает законченного измерения.

`scripts/resource-report.py FILE...` отклоняет PID reuse, сброс счётчиков и разрывы. CPU fraction относится ко всем CPU хоста. Отчёт сам по себе не подтверждает пропускную способность или безопасность платформы.
