# CSQTT OpenWrt

Клиент оригинального [CSQTT](https://github.com/amurcanov/csqtt) для OpenWrt:
вкладка LuCI, группы устройств, правила по доменам/IP и Android-помощник для
ручной CAPTCHA. Сервер разворачивается из оригинального Android-приложения.

Опубликован подписанный экспериментальный
[v0.1.0-preview.5](https://github.com/RATOR2000/csqtt-openwrt/releases/tag/v0.1.0-preview.5)
для GL.iNet GL-MT6000 / OpenWrt 25.12.5 / aarch64_cortex-a53. Сборка, подписи,
публичные файлы и обновление до r5 проверены. Четыре файла конфигурации сохранены
без изменений; VPN, DNS и разные выходы WAN/VPN работают после обновления.
Основные политики IPv4 проверены в preview.2.
Полный список проверок и оставшихся ограничений — в [STATUS.md](docs/STATUS.md).

Preview.5 добавляет галочку активности назначенных устройств: выключенное
устройство использует обычный WAN, а его запись и группа сохраняются.
Применение политик сохраняет текущий процесс VPN, если настройки подключения
не менялись. Обзор показывает объём трафика в Кб/Мб/Гб. Эти исправления проверены
через LuCI на роутере как доработки поверх r4. Автоматическое восстановление
одного канала из preview.4 также проверено на роутере; устранение периодической
потери VPN-интернета требует наблюдения.

## Установка или обновление

Выполните от root на указанной модели и версии OpenWrt:

```sh
uclient-fetch -O /tmp/csqtt-install.sh https://github.com/RATOR2000/csqtt-openwrt/releases/download/v0.1.0-preview.5/install.sh && sh /tmp/csqtt-install.sh v0.1.0-preview.5
```

Затем откройте **Службы → CSQTT** в LuCI. Установщик проверяет подписи и
контрольные суммы, сохраняет настройки и создаёт закрытую резервную копию
на роутере. Это предварительный выпуск; условия стабильного выпуска ещё
не выполнены.
