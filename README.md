# CSQTT для OpenWrt

VPN-клиент оригинального [CSQTT v2.1.9](https://github.com/amurcanov/csqtt) с управлением в браузере: выбор устройств, правила по сайтам/IP и восстановление подключения. Для работы нужны адрес сервера, пароль и ссылка на звонок VK. Сервер остаётся совместимым с оригинальным приложением CSQTT.

> Предварительный выпуск. Команда ниже предназначена для опубликованного preview.10: до его появления в разделе [Релизы](https://github.com/RATOR2000/csqtt-openwrt/releases) установка этой версии недоступна. Результаты проверок и ограничения перечисляются в описании релиза. Preview.9 предназначен для прежнего OpenWrt 25.12.5.

## Установка одной командой

Подключитесь к роутеру по SSH под `root` и вставьте строку целиком:

```sh
uclient-fetch -O /tmp/csqtt-install.sh https://github.com/RATOR2000/csqtt-openwrt/releases/download/v0.1.0-preview.10/install.sh && sh /tmp/csqtt-install.sh v0.1.0-preview.10
```

Установщик определит систему, проверит совместимость и подписи, подготовит необходимые пакеты и сохранит настройки. В конце он покажет адрес страницы настройки. Перепрошивать или перезагружать роутер не требуется.

## Что делать после установки

1. Откройте показанный адрес или **LuCI → Службы → CSQTT**.
2. В мастере введите адрес сервера, пароль и ссылку VK.
3. Выберите устройства и нажмите подключение. Результат проверки появится в браузере.

Пароли и ссылки вводятся в браузере; установщик их не запрашивает. До завершения настройки VPN выключен. При обновлении существующая конфигурация сохраняется и мастер повторно не запускается. Настоящая CAPTCHA VK может потребовать подтверждения через Android Helper.

## Совместимость

Цель текущего выпуска — официальный **OpenWrt 24.10 и 25.12**. Поддержка выбирается по архитектуре, версии системы и доступным возможностям; ограничения одной моделью роутера нет.

| Платформа | Сочетания для preview.10 |
|---|---|
| ARM64, `aarch64_cortex-a53`, target `mediatek/filogic` | Официальные 24.10.8, 25.12.5 и 25.12.6; доступность подтверждает подписанный каталог релиза |
| x86_64, target `x86/64` | Официальные 24.10.8, 25.12.5 и 25.12.6; доступность подтверждает подписанный каталог релиза |
| ARMv7 | Следующий этап проверки ABI |
| MIPS | Требуется отдельная адаптация Rust |

Проверки сборки, эмуляции и физических устройств перечисляются отдельно в релизе. Остальные сочетания target/архитектуры и версии пока не подтверждены. Если подходящей сборки, места или совместимого модуля ядра нет, установщик сообщит причину. Заводские форки, старые версии OpenWrt и snapshots в этот этап не входят.

## Обновление и удаление

Для обновления выполните команду из описания нового опубликованного релиза. Повторная установка сохраняет настройки, выбранные устройства и идентичность клиента.

Перед удалением снимите галочки активности назначенных устройств в **Устройства и политики** и примените изменения: эти устройства вернутся к обычному WAN. Затем удалите `luci-app-csqtt`, `csqtt-captcha` и `csqtt` через **Система → Пакеты**. Кнопка **Остановить** сохраняет защиту и не переводит защищённые устройства в WAN. Настройки и резервные копии автоматически не стираются.

## Если что-то не работает

Откройте **CSQTT → Диагностика**. Там отдельно показаны состояние WAN, VPN, DNS и необходимость подтверждения VK. При ошибке установки сохраните её короткое сообщение и путь к закрытому журналу; пароли и ссылки VK публиковать не нужно.

Это предварительный выпуск. Стендовые проверки и проверка на физическом роутере указываются отдельно; реальные VK/Android и длительная эксплуатация остаются отдельными условиями стабильного выпуска.
